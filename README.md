# Direwolf Cybersecurity — marketing site

Single-page static site served by GitHub Pages at
**https://www.direwolfcybersecurity.com**.

- `index.html` — the entire site (styles, scripts, and images are embedded in this one file)
- `CNAME` — tells GitHub Pages which custom domain to serve this site on

To update the live site: edit `index.html`, commit, and push to `main`.
GitHub Pages redeploys automatically within a minute or two.

The client portal / platform is a separate, private repository (`direwolf`).
